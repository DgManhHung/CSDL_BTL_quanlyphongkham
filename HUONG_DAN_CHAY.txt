  HƯỚNG DẪN CHẠY – PHÒNG KHÁM NHÓM 5

1. IMPORT DATABASE (CMD, không dùng PowerShell)
   cd C:\Users\...\PhongKham_Nhom5
   chcp 65001
   mysql -u root -p --default-character-set=utf8mb4 < database.sql

   (database.sql xóa và tạo lại phongkham_db; hãy sao lưu trước khi import.
   Dữ liệu mẫu là các câu INSERT VALUES tĩnh: 30 bệnh nhân mới mỗi tháng từ 01/2024 đến 11/2026.)
   (chcp 65001 + utf8mb4 = tránh lỗi font tiếng Việt)
   Thấy "IMPORT OK" và bảng Username/MatKhau là thành công.

2. SỬA PASSWORD MYSQL
   Mở file:
     src\main\java\com\phongkham\shared\DB.java
   Sửa:
     private static final String PASS = "password_mysql_cua_ban";

3. CHẠY APP
   IntelliJ: Open folder PhongKham_Nhom5 → Run MainApp.java
   Maven:   mvn clean javafx:run

4. ĐĂNG NHẬP
   admin   / 123456
   letan01 / 123456

   (Mật khẩu lưu plain text trong DB – dễ demo, không hash)

5. NẾU LỖI ĐĂNG NHẬP
   mysql -u root -p -e "USE phongkham_db; SELECT * FROM NguoiDung;"
   Phải thấy admin / 123456

6. FONT TIẾNG VIỆT
   - Code đã ép UTF-8 (DB.java + app.css font Segoe UI)
   - Khi import DB nhớ dùng: chcp 65001 và --default-character-set=utf8mb4
