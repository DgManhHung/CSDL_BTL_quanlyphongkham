1. IMPORT DATABASE (CMD, không dùng PowerShell)
   cd C:\Users\...\PhongKham_Nhom5
   chcp 65001
   mysql -u root -p --default-character-set=utf8mb4 < database.sql

   (database.sql xóa và tạo lại phongkham_db; hãy sao lưu trước khi import.
   File chứa dữ liệu mẫu tĩnh từ 01/2024 đến 13/11/2026: 5 bác sĩ, 7 y tá,
   1.575 bệnh nhân và 2.060 lượt khám cùng hóa đơn/thanh toán liên quan.
   Mỗi tháng đầy đủ có 60 lượt khám với giá trị hóa đơn theo gói khám chuyên sâu;
   lượt khám và hỗ trợ y tá được phân chia lệch, luân phiên giữa nhân viên theo
   tháng; tháng 11/2026 là dữ liệu lũy kế.)
   (database.sql tạo thêm bảng DotDieuTri và các view truy vấn Project 1.
   Các lần tái khám liên tiếp có thể dùng chung một đợt điều trị.)
   (Ứng dụng cũng tự bổ sung cấu trúc này nếu DB cũ đã được tạo; không cần chạy lại
   database.sql trừ khi muốn tạo lại toàn bộ DB vì script này sẽ xóa DB hiện tại.)
   (chcp 65001 + utf8mb4 = tránh lỗi font tiếng Việt)
   Cuối script có kết quả doanh thu theo tháng; tháng 11/2026 là số liệu lũy kế.

2. SỬA PASSWORD MYSQL
   Mở file:
     src\main\java\com\phongkham\shared\DB.java

3. CHẠY APP
   IntelliJ: Open folder PhongKham_Nhom5 → Run MainApp.java
   Maven:   mvn clean javafx:run

4. ĐĂNG NHẬP

   Đây là tài khoản mô phỏng; ứng dụng hiện đối chiếu mật khẩu dạng plain text.

5. NẾU LỖI ĐĂNG NHẬP
   mysql -u root -p -e "USE phongkham_db; SELECT Username,VaiTro,TrangThai FROM NguoiDung;"
   Kiểm tra tài khoản tồn tại và TrangThai='Active'.

6. FONT TIẾNG VIỆT

   - Khi import DB nhớ dùng: chcp 65001 và --default-character-set=utf8mb4
